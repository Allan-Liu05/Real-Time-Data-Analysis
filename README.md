Experiments done in my lab at UofT followed the order of setup -> run experiment -> data analysis. For someone new at the time (me), running the experiment already took a lot of time, adding on the fact that without performing the data analysis I didn't know if my collected data was viable or not. This program overcomes the issue by allowing me to look at the processed data while performing experiments.
